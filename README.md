# Projetos prontos

Biblioteca de versões utilizáveis e backups aprovados.

## Organização

- **finalizados/** — programas concluídos e aprovados em testes reais para o uso previsto.
- **estaveis/** — programas já utilizáveis e confiáveis, mas com algum ajuste de acabamento pendente.

**Este repositório não é um ambiente de desenvolvimento.** Correções e experimentos ocorrem nos laboratórios de origem; somente cópias aprovadas devem entrar nesta biblioteca.

## Projetos

- [WELLS CONECT](finalizados/WELLS-CONECT/README.md) — espelhamento e controle de aparelhos Android no Windows, com suporte a teclado físico e gamepad.
