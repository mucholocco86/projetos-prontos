# WELLS CONECT

**Classificação:** finalizado (aprovado em testes físicos pelo autor).

**Programa:** espelhamento e controle de dispositivos Android em Windows, com teclado, gamepad, áudio nos dispositivos compatíveis, captura de tela e conexão USB/Wi-Fi.

**Base técnica:** QtScrcpyCore, Qt 6, scrcpy-server 5.0.1. Os componentes de terceiros mantêm suas respectivas licenças e atribuições.
