# WELLS CONECT — versão final aprovada

**Classificação:** finalizado. **Plataforma:** Windows (portátil), com aplicativo auxiliar sndcpy no Android.

Espelhamento e controle de aparelhos Android via USB/Wi-Fi, com teclado, gamepad, áudio manual por sndcpy, captura de tela e identidade visual WELLS CONECT no executável Windows e no aplicativo Android.
